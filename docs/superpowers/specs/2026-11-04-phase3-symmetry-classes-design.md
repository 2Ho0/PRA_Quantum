# 연구 설계 (3단계): 약한/강한 대칭, 인증된 γ_c, 검증 편차, √t 법칙

작성일: 2026-11-04 · 선행: phase-1/phase-2 설계 문서

## 1. 의도

2단계 결과를 다시 보다가 해석 오류를 하나 찾았다. 이를 바로잡으면서 사용자가 승인한 네 방향을 진행한다.

- **오류.** E6b에서 "U(1) 공변이면 총 자화 분포가 정상이다"라고 썼는데 틀렸다.
  - 정리 B가 쓰는 대칭은 **약한 대칭(공변성)**이다.
  - 총 자화 분포가 정상이려면 **강한 대칭(보존)**이 필요하다.
  - 자발 방출 σ⁻는 공변이지만 M을 바꾼다.

## 2. 목표

1. **이론 — 슈퍼연산자 charge 분해.** 임의의 섭동 $\mathcal V$(Hamiltonian이든 dissipator든)를 $\mathcal V=\sum_Q\mathcal V_Q$로 나눈다. 여기서 $\mathcal V_Q$는 $\mathcal B_p$를 $\mathcal B_{p+Q}$로 보낸다.
   - 일반 선택 규칙: 1차 응답에는 $\mathcal V_0$만 기여한다.
   - Zeno 억제: $Q\ne0$ 성분은 2차이고 감쇠율이 $2\gamma_cQ^2$이다.
   - 약한/강한 대칭의 정의와, 강한 대칭이면 P(M)이 정상이라는 명제.
   - 불완전함의 세 분류: 대칭을 깨는 Hamiltonian / 공변 dissipation / 공변이 아닌 dissipation.
2. **수치 E8 (N=6).** 세 종류를 구별해 보인다.
   - 지표: ε 배증 비율, γ_c 의존성, 섹터 누출 P(M≠M₀).
   - 공변이 아닌 X-dephasing은 "공변 flip 부분 + 2차 Zeno 부분"으로 분해되는 것을 보인다.
3. **실데이터 E9.**
   - 학습 ansatz에 X/Y dephasing(공변 아님)과 흡수 σ⁺(공변이지만 강한 대칭을 깸)를 추가해서 10-ion 장치의 약한 대칭을 시험한다.
   - 구조화(γ_c11ᵀ+diag g, g≥0)와 PSD 제약 학습으로 γ_c를 다시 추정하고, bootstrap 95% 하한을 구한다. 이것이 "구조화 모델 조건부 인증" 값이다.
   - charge 분해 결맞음 감쇠(q² 법칙)의 그림자(shadow) 추정이 가능한지 판정한다.
4. **검증 편차 E6c.** 모델 변형을 비교한다.
   - 변형: 대칭 ansatz, 균일 z장, 학습 창 3 ms, 그리고 이들의 조합.
   - 관측량별 charge(0, ±1, ±2)로 나눈 검증 잔차를 본다. 특히 ⟨X₅X₆⟩의 charge 0 부분과 ±2 부분 중 어느 쪽이 틀리는지 본다.
5. **√t 법칙 (이론과 E10).** 보존 밀도와 대칭 섭동의 조합에서는 operator-norm 기반 forgetting bound가 시간에 무관해질 수 없다.
   - 확산이라는 가정 아래 integrand는 $u^{-1/2}$로 줄고, bound는 $\sqrt t$로 커진다.
   - free fermion N=200에서 확인한다.
