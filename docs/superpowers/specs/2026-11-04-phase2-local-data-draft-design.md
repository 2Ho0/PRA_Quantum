# 연구 설계 (2단계): 국소화된 Zeno bound · BEQS 실데이터 재학습 · PRA 원고 초안

작성일: 2026-11-04 · 선행 설계: `2026-11-04-dissipative-error-anatomy-design.md` · 저장소: https://github.com/2Ho0/PRA_Quantum

## 1. 의도와 이유

1단계 결과에서 PRA 투고 전에 메워야 할 빈칸 세 가지를 채운다.

1. **정리 B3이 N에 따라 커진다.** 전역 $\lVert\delta H\rVert$를 쓰기 때문이다. 국소 관측량의 실제 오차는 N과 무관하다(E5). 계(system) 크기와 무관한 bound가 있어야 다체 물리 논문으로 완결된다.
2. **실데이터 그림이 없다.** 1단계에서는 "원시 shot만 있다"고 판정해 보류했다. 다시 확인한 결과 다음과 같다.
   - **10-ion 데이터.** 측정 기저가 파일에 없다. 하지만 두 초기 상태가 알려진 곱 상태이다(BEQS 부록: θ=0.33π, −y축 / θ=0.5π, x축). 그래서 t=0 통계만으로 각 설정의 Pauli 기저를 복원할 수 있다.
     - 상태 1에서는 X ≈ +0.87, Z ≈ −0.45, Y ≈ 0의 세 군집으로 깨끗하게 갈린다.
     - 상태 2의 Y 군집(≈ +1)과도 모든 설정에서 일치한다.
     - 따라서 integral method로 생성자를 다시 학습할 수 있다.
   - **51-ion Hamiltonian-learning 데이터.** 설정이 번호로만 저장되어 있어 사용할 수 없다.
   - **51-ion Néel 데이터.** z-기저라서 그대로 쓸 수 있다.
3. **원고가 없다.** 이론 노트와 그림을 PRA 형식 원고로 묶는다.

## 2. 목표 · 비목표 · 반목표

- **목표**
  1. 정리 B3′을 증명한다. 교환자 형태이고, 모든 차수에서 엄밀하며, 기준 동역학만 쓴다.
  2. Lieb–Robinson 따름정리 B3-loc을 증명한다. N과 무관한 bound다.
     - 핵심 관찰: charge 사영, 모든 z-dephasing(집단 dephasing 포함), on-site 항은 연산자의 지지집합을 넓히지 않는다. 그래서 LR 속도는 Hamiltonian의 국소 항만으로 정해진다.
  3. E7: free fermion N=20–200에서 확인한다.
     - B3′ 증명서(certificate)는 N과 무관하다.
     - 전역 B3은 N²로 커진다.
     - 관측 오차는 증명서 아래에 있다.
  4. E6 (10-ion): 기저를 복원하고 integral method로 학습한다.
     - 학습 대상: H(XX, YY, XY, YX, 단일 사이트 X/Y/Z), dephasing 행렬 Γ, 방출률.
     - 학습 창은 BEQS와 같은 t ≤ 1.5 ms이고, 이후 시간(≤ 10 ms)은 검증에 쓴다.
     - 학습된 모델에서 계산할 것: $\gamma_c^*$, charge 분해(대칭 / 깨는 성분과 그 불확실성), 오차 예산(우리 bound 대 BEQS bound).
  5. E6 (51-ion Néel): 총 자화 분포 $P(M,t)$의 정상성을 검사한다. U(1) 공변성을 실험에서 직접 진단하는 것이다.
  6. revtex4-2 PRA 원고 초안 + 벡터 그림을 만들고, 로컬 TeX Live로 컴파일한다.
- **비목표**
  - 51-ion 모델 재학습 (설정 정의가 없음)
  - 새로운 학습 프로토콜
  - 원고 투고나 저자 연락 (초안만 작성)
- **반목표**
  - 복원한 기저를 확인된 사실처럼 쓰는 것. 원고에는 "추론했다"고 쓰고 확인 요청 초안을 남긴다.
  - BEQS의 학습 결과를 반박하는 프레이밍. 우리 결과는 그들의 데이터를 재사용한 독립 분석이다.
  - 원시 데이터를 git에 올리는 것. 다운로드 스크립트로 대신한다.

## 3. 결정 사항 (Claude의 판단)

- **브랜치.** 작업은 `phase2-local-data-draft` 브랜치에서 한다. 끝나면 `main`으로 PR을 연다. 초기 import는 `main`에 있다(e6240ed).
- **단위.**
  - 이론 실험: $J_0=1$.
  - 이온 데이터: 시간은 ms, 파라미터는 rad/ms. 보고할 때는 BEQS와 같은 rad/s로 바꾼다.
- **Free fermion 규약.** E5와 같다. 집단 jump는 $\sqrt{\gamma_c}N$이고 pairing 블록 감쇠율은 $2\gamma_c$이다.
- **학습 시간 적분.** 학습 창 안의 측정점에 cubic spline을 맞춰 적분한다(창 밖 점은 쓰지 않음). 이산화 편향은 합성 데이터 테스트로 잰다.
- **불확실성.** 설정(200개)을 복원추출하는 bootstrap을 쓴다.
- **원고.** revtex4-2, `pra`, 두 단 형식. 그림은 PDF이다.

## 4. 성공 기준

- E7: 증명서 ≥ 관측(모든 N, γ_c, t), 증명서의 N 의존성 < 5% (N ≥ 100), 전역 bound 비율 N=200/N=50 ≈ 16.
- E6: 학습된 $J_{ij}$가 BEQS 보고값($J_0\approx576$ rad/s, $\alpha\approx1.19$)과 같은 크기이다. 검증 창(1.5–10 ms) 예측이 측정값과 맞는 정도를 수치로 보고한다.
